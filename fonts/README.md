# Local fonts · Stage 2A

Instrument Serif 400 normal and Public Sans variable normal (used at 400/500) are self-hosted from Google Fonts. OFL 1.1 texts are included alongside the fonts; preserve these notices when redistributing. Verified 2026-11-17. No runtime Google Fonts request.

Sources:
- https://github.com/google/fonts/tree/main/ofl/instrumentserif
- https://github.com/google/fonts/tree/main/ofl/publicsans

The exact official TTF files are used without modification. Total font binary size is 173,328 bytes. WOFF2 optimization remains a later delivery task; no conversion dependency was added. CSS uses font-display:swap and preloads only Instrument Serif; fallback remains for loading failures.
